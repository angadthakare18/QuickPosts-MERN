# 🚀 QuickPosts-MERN

A lightweight **MERN Stack** project built to strengthen core full-stack development concepts. **QuickPosts** allows users to create posts and view them in a feed.

This project is **not a social media platform**. Instead, it serves as a hands-on learning project focused on understanding how modern web applications handle user , API communication, image uploads, and client-server interactions.

## ✨ Features

* 📝 Create new posts
* 📃 View all posts in a centralized feed
* 🖼️ Image upload and management using **ImageKit**
* 🌐 API integration
* 🔄 Client-server communication using **Axios**
* 🛡️ Cross-Origin Resource Sharing (CORS) configuration
* ⚡ Clean and simple MERN architecture

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/angadthakare18/QuickPosts-MERN
cd QuickPosts-MERN
```

### 2. Install Dependencies

Install dependencies for both frontend and backend. As there is no node_module folder.

```bash
npm install
```

### 3. Start the Backend Server

Navigate to the backend folder and run:

```bash
npx nodemon server.js
```

✅ Make sure you are inside the backend directory where `server.js` is located before running the command.

### 4. Start the Frontend

Run the frontend application and open it in your browser.

## 🎯 Project Goal

The main objective of **QuickPosts-MERN** is to gain practical experience with real-world MERN stack development by implementing core backend and frontend concepts in a simple and easy-to-understand project.
